RPM Counter

Why I created it

I built this to measure my Long Lasting Spinning Top. Neodymium Magnets on the top trigger a Hall Effect Sensor, and an Arduino Uno Clone sends live RPM data to my computer via USB-C. I originally got the idea to build an RPM counter to replicate the data shown in a Formula One car, where each detail about the car's RPM is crucial in knowing what gear the car should be in.
